# Applications de test

Ce dossier accueille l'APK Android utilisé par le profil `test:native`.

Télécharger la dernière release de **Sauce Labs My Demo App (Android)** :
https://github.com/saucelabs/my-demo-app-android/releases

Placer le fichier `.apk` téléchargé ici sous le nom `my-demo-app-android.apk`,
ou définir la variable d'environnement `ANDROID_APP_PATH` pour pointer vers
un autre emplacement.
